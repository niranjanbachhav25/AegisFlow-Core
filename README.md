# 🛡️ AegisFlow - AI-Driven Web Application Firewall & Security Agent

AegisFlow is a professional-grade, intelligent Web Application Firewall (WAF) and security monitoring system. Built with a Client-Server architecture, it actively monitors real-time server logs to detect brute-force attempts, analyze threat patterns, and automatically initiate remediation actions like IP blocking.

## 🚀 Features
* **Real-Time Log Monitoring:** Continuous tracking of server authentication logs (`auth.log`).
* **Brute-Force Detection:** Advanced threshold-based logic to detect and flag suspicious login activities.
* **Automated Threat Remediation:** Identifies malicious IP addresses and triggers an automated blocking mechanism after consecutive failed attempts.
* **Enterprise UI Target Simulator:** Includes a secure, modern dark-themed Admin Portal to simulate real-world attack vectors and generate live logs.
* **(Upcoming) AI-Powered Bot Detection:** Machine Learning integration (XGBoost/Random Forest) to distinguish between human errors and automated bot attacks.

## 🛠️ Tech Stack
* **Backend:** Python, Flask
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
* **Security Logic:** Python File Handling, Log Parsing, Threshold Tracking
